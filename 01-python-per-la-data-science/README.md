## GitHub
**Repo pubblica:** [data-science](https://github.com/davidefella/data-science) — esercizi, script di live coding e dataset campione (`.sample.csv`)
**Repo privata:** `ds-datasets` — dataset reali (Fitbod, MoneyLover, Apple Health), mai pushati pubblicamente. I file reali non richiedono anonimizzazione: il `.gitignore` li esclude automaticamente dalla repo pubblica.
Struttura repo pubblica:
```javascript
data-science/
├── 00-datasets/                        # Solo .sample.csv — dati simulati
│   ├── WorkoutExport.sample.csv
│   ├── wallet.sample.csv
│   ├── investments.sample.csv
│   └── health.sample.csv
└── 10-python-ds-fundamentals/
    └── 01-numpy/
        ├── numpy_demo.py
        └── Laboratorio/
            ├── 01_basics.py
            ├── 02_intermediate.py
            └── 03_advanced.py
```
> I file reali (`WorkoutExport.csv`, `wallet.csv`, `investments.csv`, `health.csv`) si ottengono da `ds-datasets` e si copiano in `00-datasets/` localmente. Il `.gitignore` li esclude automaticamente dalla repo pubblica.
